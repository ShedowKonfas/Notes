# AGENTS.md

Назначение: Tkinter-приложение для заметок — файлы `*.note` в текущей папке, список, редактирование, удаление.
## Карта файлов

| Файл | Роль |
|---|---|
| `Main.py`, `MainWindow.py` | точка входа, окно, карточки и кнопки |
| `Note.py`, `Methods.py`, `TextEditWindow.py` | файлы заметок, поиск `*.note`, редактор |
| `Main.spec`, `Notes.ico` | сборка PyInstaller и иконка |
## Запуск и проверка

`python Main.py`; сборка — `pyinstaller Main.spec`. Запуск только из папки проекта.
Тестовой команды нет; не выдумывай тесты без запроса пользователя.
## Соглашения

- Интерфейс и документация — на русском; формат заметки — текстовый файл `.note`.
- Новые действия добавляй в `MainWindow` и сразу описывай в README.
## Подводные камни

- `get_note_list()` ищет файлы в текущем каталоге, а не рядом с exe.
- Удаление в интерфейсе вызывает `os.remove()` без восстановления.
- Кодировка не задана; `build\` и exe не удаляй без разрешения.
## Запреты

- Не удаляй файлы без разрешения пользователя.
- Не трогай системные файлы.
- Не меняй код, spec и формат заметок без запроса.
- Не делай commit/push без явной просьбы.
