# Notes — приложение для заметок

Desktop-приложение на `tkinter`: заметки хранятся обычными файлами `*.note` в текущей папке, список показывается в окне.

## Быстрый старт

```bat
python Main.py
```

Запускать нужно из папки проекта: список заметок берётся через `os.listdir()` из текущего рабочего каталога.

## Возможности

- кнопка `+` создаёт заметку (`note-<uuid>.note` или имя, введённое в диалоге);
- «Редактировать» открывает окно с текстом и кнопкой «Сохранить»;
- «Удалить» спрашивает подтверждение и удаляет файл;
- список обновляется после создания и удаления.

## Сборка EXE

```bat
pyinstaller Main.spec
```

Spec собирает консольное окно выключенным (`console=False`), иконка — `Notes.ico`. В корне также лежит уже собранный `Notes.exe`.

## Структура

| Файл | Роль |
|---|---|
| `Main.py` | точка входа |
| `MainWindow.py` | главное окно, список и кнопки |
| `Note.py` | чтение, запись, удаление и создание файлов заметок |
| `Methods.py` | поиск файлов `*.note` |
| `TextEditWindow.py` | окно редактирования |
| `Main.spec` | конфигурация PyInstaller |
| `README.md`, `AGENTS.md` | документация |

## Подводные камни

- Заметки — это файлы в рабочей папке: удаление в интерфейсе удаляет файл безвозвратно.
- Кодировка не задана, используется системная по умолчанию.
- Тестов и `requirements.txt` нет.
